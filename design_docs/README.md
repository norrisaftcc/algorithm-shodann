## understanding the design docs
The files in this folder represent the current plan.
Files in the "prototype" subfolder represent documents used to get to the current plan. While they might be out of date, they may provide useful corroborating information.

### Repository subscription docs
- `ONBOARDING_A_REPOSITORY.md` — the detailed technical write-up for subscribing a second repository to SHODANN, including the prerequisites and the history of the blockers that the reusable workflow fixed.
- `SUBSCRIBING_TO_SHODANN.md` — a shorter, maintainer-facing overview of the subscription checklist and the main risks.
- `SHODANN_SUBSCRIPTION_TROUBLESHOOTING.md` — a compact symptom guide for the most common subscription failures.
- `TESTING_SHODANN_ON_HAIKU_5_5.md` — how to test the Anthropic primary wire and the reusable workflow, from the offline suite through a pilot repository, and where to record what a run finds.
- `SUBSCRIBING_A_CTS285_REPOSITORY.md` — the CTS-285 runbook over the three documents above. It enables nothing: it is gated on a course-owner ruling.
