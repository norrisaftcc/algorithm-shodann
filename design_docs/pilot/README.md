# The Pilot

`session-one-ledger.html` is a static print of SHODANN's velocity engine
measuring the session that built SHODANN, frozen at `3a421fd` on 2026-07-25.

**It is never updated.** The live dashboard keeps moving; this one is the
record of what season one looked like from inside it. Fourteen merge points,
471.40 cumulative velocity, 147 test functions from a standing start, one
sitting.

Open it in any browser. Everything is inline - no fonts, no scripts, no
network. It renders in light and dark, and every figure a chart shows is
repeated in the ledger table beneath it, because a chart nobody can read is a
decoration.

## Why keep it

The numbers are not the point. Three of the fourteen merges score at the floor
because they were documentation and tooling with no test growth, and the page
says so plainly rather than smoothing the line - the same instrument, applied
to its own authors, reporting a foundation phase as a foundation phase.

The coverage disclosure is on it too: nothing measured coverage during season
one, so every coverage delta is zero, and the page states that where a reader
will see it rather than letting a flattering number stand.

That is the whole argument for the project in one artifact. Measure the
derivative, disclose the gaps, and let the shape of the work show.

## Companion

`design_docs/EARLY_RUNS.md` is the prose twin - what SHODANN actually said
while it was wrong, and what each defect cost to find. Read together, they are
the same season from two angles: what the instrument recorded, and what the
instrument got wrong.
